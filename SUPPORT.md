# Getting help

- **Installing:** start with the [install guides](https://enveliq.app/docs/install/), then [Troubleshooting](https://enveliq.app/docs/install/troubleshooting/).
- **Still stuck, or something is not working:** [open an issue](https://github.com/jlnau/enveliq/issues/new/choose) and pick the form that fits. Never paste real email, passwords or keys.
- **A security problem:** use the [private form](https://github.com/jlnau/enveliq/security/advisories/new), not a public issue.
- **An idea or a request:** [open an issue](https://github.com/jlnau/enveliq/issues/new/choose) and pick "I have an idea".
